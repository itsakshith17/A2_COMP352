    Algorithm StringTester(String input)
        Input A string of length n made of characters '(',')' and '*' in random order and repetition.
        The Input string always ends with '$'. '*' is a wildcard that can act as '(', ')' or be ignored to make
        sure that every open parenthesis has a closing parenthesis
        Output True if the string is valid, False otherwise

        Let S be an empty Stack
        let k be the minimum number of open parentheses allowed on the stack
        let isValid be a bolean value that says if the String is valid
        for i = 0 to n-1 do
            current = input.charAt(i)
            if current = '$' then
                isValid = (k = 0)
                break
            else if current = '(' then
                S.push(current)
                k++
            else if current = ')'then
                if S.isEmpty() then
                    break
                S.pop()
                if k > 0 then
                    k--
            else if current = '*' then
                S.push(current)
                if k > 0 then
                    k--
        return isValid
